## 1. Address Search (REST)
GET https://ipi.eprostor.gov.si/jv-api/search?filter={query}&source=NSLV-STA-FULL

Example:
  https://ipi.eprostor.gov.si/jv-api/search?filter=Resljeva%20cesta%2010%20Ljubljana&source=NSLV-STA-FULL

Returns JSON array of "features" with:
  - ULICA_NAZIV         : street name
  - HS_STEVILKA         : house number
  - NASELJE_NAZIV       : settlement
  - OBCINA_NAZIV        : municipality
  - POSTNI_OKOLIS_NAZIV : post office area
  - E, N                : coordinates in EPSG:3794 (D96/TM Slovenian national grid)
  - EID_STAVBA          : building entity ID
  - EID_HISNA_STEVILKA  : house number entity ID

## 2. OGC API - Features (RECOMMENDED — returns GeoJSON directly)
Base URL: https://ipi.eprostor.gov.si/wfs-si-gurs-kn/ogc/features

### List all layers (collections)
GET /collections
  → https://ipi.eprostor.gov.si/wfs-si-gurs-kn/ogc/features/collections?f=application/json

### Get features from a layer as GeoJSON
GET /collections/{layerId}/items?f=application/geo+json&bbox={minLon},{minLat},{maxLon},{maxLat}&limit=N

Example — get parcels in Ljubljana area:
  https://ipi.eprostor.gov.si/wfs-si-gurs-kn/ogc/features/collections/SI.GURS.KN:OSNOVNI_PARCELE/items?f=application%2Fgeo%2Bjson&bbox=14.49,46.03,14.55,46.08&limit=5

### Key layers (30+ available)
  SI.GURS.KN:OSNOVNI_PARCELE       — parcel polygons + EID, KO_ID, ST_PARCELE, POVRSINA (area), centroid
  SI.GURS.KN:OSNOVNI_STAVBE        — building polygons
  SI.GURS.KN:STAVBE_OBRIS          — building outlines
  SI.GURS.KN:STAVBE_TLORIS         — building floor plans
  SI.GURS.KN:GRADBENE_PARCELE      — building parcels
  SI.GURS.KN:HISNE_STEVILKE        — house number points
  SI.GURS.KN:NASLOVI_HS            — addresses linked to house numbers
  SI.GURS.KN:DEJANSKE_RABE         — actual land use (polygons)
  SI.GURS.KN:NAMENSKE_RABE         — planned land use (polygons)
  SI.GURS.KN:KATASTRSKE_OBCINE     — cadastral municipality boundaries
  SI.GURS.KN:BONITETE              — soil quality
  SI.GURS.KN:GOZDNO_GOSP_OBM       — forest management areas
  SI.GURS.KN:UREJENE_MEJE          — arranged boundaries
  SI.GURS.KN:DELI_STAVB            — building parts
  SI.GURS.KN:ETAZE                 — floors/condominium units
  SI.GURS.KN:PARCELE_JAVNI_LASTNIKI — publicly owned parcels

### Get a single feature by ID
GET /collections/{layerId}/items/{featureId}?f=application/geo+json

### Other WFS services (see section 8 for enriched parcel inquiry)
- wfs-si-gurs-ev  — Mass Valuation (EV)
- wfs-si-gurs-kgi — Public Infrastructure Cadastre (KGI)
- wfs-si-gurs-rn  — Real Estate Register (RN)
- wfs-si-gurs-etn — Market Transactions (ETN) — documented but 404 on production
All also have OGC API endpoints at the same base path.

## 3. WFS — Classic OGC Web Feature Service (XML)
https://ipi.eprostor.gov.si/wfs-si-gurs-kn/wfs

GetCapabilities (list all layers):
  ?service=WFS&request=GetCapabilities

GetFeature (parcels in bbox, max 3):
  ?service=WFS&request=GetFeature&version=2.0.0
  &typeNames=SI.GURS.KN:OSNOVNI_PARCELE
  &srsName=EPSG:3794
  &bbox=462000,101500,462300,101800,EPSG:3794
  &count=3

Note: prefers OGC API - Features (section 2) for new development — GeoJSON is much easier.

## 4. WMS — Raster Map Layers
https://ipi.eprostor.gov.si/wms-si-gurs-kn/wms

GetCapabilities:
  ?service=WMS&request=GetCapabilities

GetMap example:
  ?service=WMS&request=GetMap&layers=SI.GURS.KN:OSNOVNI_PARCELE
  &bbox=...&width=800&height=600&srs=EPSG:3794&format=image/png

27 layers available (same layer names as WFS above, plus orthophoto).

Use with Leaflet: L.tileLayer.wms(url, { layers: 'SI.GURS.KN:OSNOVNI_PARCELE', ... })

## 6. Coordinate Systems
- GURS native:  EPSG:3794 (D96/TM — Slovenian national grid, meters)
- Leaflet/Web:  EPSG:4326 (WGS84 — lat/lon degrees)

The OGC API - Features (section 2) handles reprojection automatically
when you use f=application/geo+json and WGS84 bbox coordinates.

For classic WFS/WMS in EPSG:3794, you need proj4 to convert to EPSG:4326:
  const d96 = '+proj=tmerc +lat_0=0 +lon_0=15 +k=0.9999 +x_0=500000 +y_0=-5000000 +ellps=GRS80 +towgs84=0,0,0,0,0,0,0 +units=m +no_defs';
  proj4(d96, 'EPSG:4326', [x, y]); // returns [lon, lat]

## 7. What Requires Authentication
These services exist but require GURS credentials or legal authorization:
- Owner names and personal data (EV layers: OSEBA, PRAVICA_LASTNISTVA, IMETNIK_LASTNISTVA)
- Flood/erosion risk layers — not in ARSO public GeoServer; likely MOP/DRSV or GURS auth
- Bulk/full-database downloads (JGP portal has public subset, full may need auth)
- ETN WFS (documented but returns 404 on production — may be test-only)

These require GURS credentials or direct partnership (Omsoft has this).

## 8. Enriched Parcel Inquiry — Fetch-All Pattern

When a user selects a parcel, fetch these layers in parallel for enriched data:

### 8a. STAVBE (Building Details) — via OGC API bbox or WFS INTERSECTS
  OGC API: /collections/SI.GURS.KN:STAVBE/items?f=geo+json&bbox=...&limit=5
  WFS: cql_filter=INTERSECTS(GEOM,POINT(E N)) on STAVBE

Key fields (human-readable Slovenian):
  LETO_IZGRADNJE         : year built (e.g. 1978)
  LETO_OBNOVE_FASADE     : facade renovation year
  STEVILO_ETAZ           : number of floors (e.g. 6)
  STEVILO_STANOVANJ      : number of apartments (e.g. 92)
  BRUTO_TLORISNA_POVRSINA: gross floor area in m²
  TIPI_STAVB_NAZIV_SL    : building type ("samostoječa stavba")
  NOSILNE_KONSTRUKCIJE_NAZIV_SL : construction ("beton, železobeton")
  ELEKTRIKA_NAZIV_SL     : has electricity? ("Da")
  VODOVOD_NAZIV_SL       : has water? ("Da")
  KANALIZACIJA_NAZIV_SL  : has sewage? ("Da")
  STEVILO_POSLOVNIH_PROSTOROV : number of business premises
  VISINA_H1, VISINA_H2, VISINA_H3 : building heights (m) — for 3D extrusion
  ST_STAVBE              : building number within KO
  OBRIS_GEOM             : building outline polygon (WGS84 GeoJSON!) — for 3D
  TLORIS_GEOM            : terrain footprint polygon (WGS84 GeoJSON!)
  RPE_OBCINE_NAZIV       : municipality name
  STATUSI_VPISA_STAVBE_NAZIV_SL : registration status ("Katastrski vpis po ZEN")
  POLOZAJNE_NATANCNOSTI_STAVBE_NAZIV_SL : coordinate accuracy

### 8b. DEJANSKE_RABE (Actual Land Use) — via OGC API bbox
  /collections/SI.GURS.KN:DEJANSKE_RABE/items?f=geo+json&bbox=...&limit=10

Key fields:
  MASKA_IME              : combined land use mask ("Hkratna raba zemljišča")
  MASKA_SFR              : mask code
  B_POSELJENO_ID         : settlement classification ID
  E_STAVBA_ID            : building ID (partial, last 8 digits of EID_STAVBA)
  LOKACIJSKA_NAT         : location accuracy

### 8c. NAMENSKE_RABE (Planned Land Use / Zoning) — via OGC API bbox
  /collections/SI.GURS.KN:NAMENSKE_RABE/items?f=geo+json&bbox=...&limit=10

Key fields (human-readable Slovenian!):
  PODROBNE_NAMENSKE_RABE_NAZIV_SL : zoning label (e.g. "CD")
  PODROBNE_NAMENSKE_RABE_OPIS_SL  : zoning description ("Druga območja centralnih dejavnosti")
  PODROBNE_NAMENSKE_RABE_SIFRA    : zoning code

### 8d. BONITETE (Soil Quality) — via OGC API bbox
  /collections/SI.GURS.KN:BONITETE/items?f=geo+json&bbox=...&limit=10

Key fields:
  BONITETA              : overall soil quality score (0-100)
  TOCKE_TLA             : soil points
  TOCKE_KLIMA           : climate points
  TOCKE_RELIEF          : relief/terrain points
  TOCKE_POSEBNOSTI      : special characteristics points
  POVRSINA              : area in m²

### 8e. EV — Mass Valuation (wfs-si-gurs-ev) ⭐ NEW
  WFS: https://ipi.eprostor.gov.si/wfs-si-gurs-ev/wfs
  OGC API: https://ipi.eprostor.gov.si/wfs-si-gurs-ev/ogc/features/collections

Key layers:
  SI.GURS.EV:PARCELA         — parcel valuation data
    Fields: BONITETA, ODPRTOST, POVRSINA, PARCELA, EID_PARCELA, KO_SIFKO
  SI.GURS.EV:NRP_PARC        — land use classification for valuation
    Fields: NAZIV_NR_PARC (e.g. "druga kmetijska zemljišča"), DELEZ (%)
  SI.GURS.EV:STAVBA          — building valuation data
    Fields: LETO_IZG_STA, LETO_OBN_STREHE, ST_ETAZ, POV_STAVBE,
            NAZIV_KONSTRUKCIJA, NAZIV_TIP_STAVBE, ZPS_STAVBA
  SI.GURS.EV:DEL_STAVBE      — building part valuation
  SI.GURS.EV:STA_PAR         — building-parcel relationship

Note: SLAVBA and PARCELA layers contain valuation attributes.
Personal/ownership layers (OSEBA, PRAVICA_LASTNISTVA) exist but likely require auth.

### Recommended Fetch Pattern for Enriched Parcel Inquiry
When parcel is selected, fire parallel requests:
  1. KN STAVBE in bbox → building details + heights + outline
  2. KN DEJANSKE_RABE in bbox → actual land use
  3. KN NAMENSKE_RABE in bbox → zoning
  4. KN BONITETE in bbox → soil quality
  5. EV PARCELA by EID_PARCELA → mass valuation data
  6. EV STAVBA by EID_STAVBA → building valuation
All OGC API layers return WGS84 GeoJSON directly.
WFS (EV, KGI) require EPSG:3794 → EPSG:4326 transform via proj4.
Use turf.booleanPointInPolygon to match polygon layers to the selected parcel.
