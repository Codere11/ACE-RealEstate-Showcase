# ACE — Startup Runbook

## Quick Start

```bash
docker compose -f docker-compose-simple.yml up -d
```

Starts PostgreSQL (5433), LiveKit (7880), Backend (8000).

Auto-seeds: demo org, admin user (`admin`/`test123`), AI qualifier.

## Open

| URL | What |
|---|---|
| `http://localhost:8000/demo` | Visitor chatbot |
| `http://localhost:8000/demo/dashboard` | Staff dashboard |
| `http://localhost:8000/login` | Login (admin / test123) |

## Local Dev

```bash
# Stop Docker backend, run locally with reload
docker compose -f docker-compose-simple.yml stop backend
cd backend && source ../venv/bin/activate
PYTHONPATH=.. uvicorn main:app --port 8000 --reload
```

## Angular Dev

```bash
cd angular-visitor && npm start   # port 4200, proxies API to :8000
```

Use `http://localhost:8000` for the real app. Dev server is for editing components.

## Rebuild Frontend

```bash
cd angular-visitor && npm run build
cp -r dist/angular-visitor/browser/* ../backend/static/
```
